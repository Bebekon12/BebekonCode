# Changelog

Every release links to a version tag and includes the same reviewed notes in GitHub Releases.

## 0.5.0 — 2026-10-07

### Полная рабочая область и общий итог команды

- Проекты в левой панели раскрываются в дерево обычных и командных чатов. Разговоры без проекта находятся в отдельных разделах: «Обычные чаты», «Команды агентов», «Авторазбиение». Чаты не дублируются.
- Кнопки создания возле разделов открывают нужный режим; новый чат в папке привязан к выбранному проекту. Сворачивание папок сохраняется.
- Переписка расширена до 1080 px, поле ввода — до 1024 px. Заголовок и поле ввода занимают меньше места; постоянной панели настроек команды нет.
- Сообщения пользователя остаются справа, ответы — слева. Мультиагентный чат показывает один «Ответ команды», уже собираемый основным агентом; результаты участников открываются отдельно.
- Меню команды раскрывает роли, модели, персональные настройки и историю подзадач, не уменьшая область чата. Во время подготовки общего результата отображается фактический этап работы.
- Файлы, PowerShell и Git-изменения доступны из заголовка проекта. Добавлено отдельное окно списка файлов и diff текущих изменений Git.
- Раздел «Плагины» показывает подключённые плагины, MCP-серверы и навыки выбранного аккаунта и позволяет перейти к назначению инструментов конкретному агенту.
- Запросы разрешений и ошибки остаются видимыми при свёрнутом ответе. Тема, крупный текст, остановка и передача контекста сохранены.

### Текущие ограничения

Это ранняя версия. Изменения касаются интерфейса; реальная интеграция остаётся OpenAI / Codex, Claude Code пока недоступен. Оркестрация проверена тестовыми провайдерами, сценарии на живых подписках требуют отдельной проверки. Параллельные участники работают только на чтение; итог и изменения выполняет основной агент. Git worktree, установка новых расширений из приложения и встроенный терминал пока недоступны: кнопка «Терминал» открывает отдельное окно PowerShell. Подпись обновления Tauri проверяется; сертификата Windows Authenticode нет. Полный цикл установки обновления и перезапуска на установленной копии ещё требует проверки.

### Проверки

Пройдены cargo fmt/check/test/clippy, npm typecheck/test/build и 14 сценариев интерфейса. В собранном Windows EXE проверены файловые операции и конфликты сохранения, Git diff, командный итог, отдельные контексты, передача контекста и сохранение настроек. Официальный updater проверил подписанный установщик и отверг изменённый пакет и неверную подписанную версию.

### Читаемый интерфейс

- Переписка расположена в широкой центральной колонке. Сообщения пользователя — компактные блоки справа; ответы агента — обычный текст без обрамления карточкой.
- Удалены декоративный баннер с планетой, повторяющиеся статусы и нижняя техническая строка. Упрощены меню, приветствие и настройки возле поля ввода.
- Панель проекта закрыта по умолчанию, открывается кнопкой в правом верхнем углу и запоминает выбранное состояние.
- Подписи больше не используют шрифты 9–12 px. Сохранены доступ к инструментам, переход между исполнителями, история действий и запросы разрешений.
- Исправлено обрезание приветствия пустого чата при крупном тексте и небольшом окне.

### Текущие ограничения

Это обновление интерфейса ранней версии. Реальная интеграция остаётся OpenAI / Codex; Claude Code пока недоступен. Командные сценарии проверены тестовыми провайдерами, работа на живых подписках требует отдельной проверки. Параллельные участники анализируют проект только на чтение; Git worktree и установка новых расширений внутри приложения ещё не реализованы. Подпись обновления Tauri проверяется, но отдельного сертификата Windows Authenticode нет; полный цикл установки обновления и перезапуска на установленной копии ещё требует проверки.

## 0.4.0 — 2026-10-06

### Чаты как основной сценарий

- «Новый чат»: обычный разговор без обязательного проекта, команда агентов или авторазбиение.
- Модель, уровень рассуждения, доступ, инструменты и переход — возле поля ввода.
- «Перейти» просит текущего агента пересказать задачу и передаёт контекст новому исполнителю в том же чате. При ошибке прежняя привязка сохраняется.
- Роли и персональный выбор уже подключённых плагинов, MCP и навыков для каждого участника.
- Команда обменивается результатами и проводит один раунд обсуждения; основной агент собирает ответ.
- Авторазбиение создаёт до четырёх самостоятельных контекстов с общей целью, по два параллельно. История и результаты подзадач сохраняются и доступны из чата.
- Миграция сохраняет существующие чаты и потоки. История новых ответов сохраняет сведения о модели и провайдере.
- Упрощена навигация: чаты отдельно от проектов, аккаунты доступны прямо из меню, действия и фильтры истории сворачиваются.

### Текущие ограничения

Это ранняя версия, а не заявление о готовности всей системы к production. Реальный адаптер сейчас — OpenAI / Codex через Sign in with ChatGPT. Claude Code ещё не подключён; команда Claude + GPT пока недоступна. Работа на живых подписках, реальная доступность моделей, перенос между провайдерами и расширения требуют отдельной проверки. Ядро оркестрации проверяется тестовыми провайдерами, интерфейс — предпросмотром, локальные сценарии — отдельным Windows-приложением.

Участники анализируют проект в песочнице только на чтение; изменения выполняет основной агент с выбранными разрешениями и запросами подтверждения. Git worktree, произвольные циклы делегирования и восстановление выполнения после сбоя ещё не реализованы. Установка новых расширений — через официальный CLI; здесь назначаются уже установленные. Генерация изображений через текущий путь плана ChatGPT недоступна.

Обновления остаются подписанными и устанавливаются внутри приложения. Полный цикл обновления установленной копии и перезапуска ещё требует отдельной проверки. Authenticode пока не настроен.

## 0.3.2 — 2026-10-06

### Обновление внутри приложения

- В «Настройки → О программе и обновления» можно скачать, установить новую версию
  и автоматически открыть приложение снова без ручного запуска установщика.
- Подпись каждого пакета проверяется официальным Tauri updater по встроенному открытому ключу.
  Повреждённый пакет или пакет с другой подписью не устанавливается.
- Показаны описание версии, подтверждение установки и прогресс загрузки. Перед обновлением
  нужно остановить активные сессии. Во время установки настройки и окно защищены от закрытия.
- Windows обновляется подписанным setup.exe в режиме passive с небольшим окном прогресса.
  Перезапуск выполняет установщик. Проекты и история используют прежний каталог данных.
- GitHub Releases содержит latest.json, установщики и подписи. CI подписывает новые выпуски
  защищённым ключом и публикует выпуск после загрузки файлов обновления.

### Ограничения

- Версии до 0.3.2 не содержат updater: переход на 0.3.2 один раз выполняется через setup.exe.
- Подпись обновления Tauri не является Windows Authenticode; предупреждение SmartScreen
  может сохраняться до настройки отдельного сертификата.
- Полная проверка обновления на пользовательской установленной копии не выполнялась.
- Ограничения Codex и остальных возможностей из 0.3.1 сохраняются.

## 0.3.0 — 2026-10-06 (pre-release)

Предварительный выпуск. Подключение OpenAI / Codex проверено автоматическими тестами и на
установленном Codex CLI без реального входа; вход Sign in with ChatGPT и ответы модели ещё не
проверены на живом аккаунте. Проверка обновлений в приложении предварительные выпуски не
предлагает — установите его вручную.

Лицензия проекта — MIT.

### OpenAI / Codex

- Подключён официальный `codex app-server` (проверено с codex-cli 0.160.1).
- Вход через Sign in with ChatGPT по документации OpenAI для open-source и локальных приложений:
  кнопка «Continue with ChatGPT», отдельная регистрация (client_id) на каждый аккаунт, PKCE,
  проверка подписи ID-токена, обновление и отзыв токенов. Пароль вводится только на сайте OpenAI.
- Несколько аккаунтов ChatGPT одновременно: у каждого свои токены (Windows DPAPI) и своя папка
  Codex. Добавление, переименование, выход и удаление аккаунта.
- Сессии Codex: потоковый ответ, команды, изменения файлов, MCP, поиск, план; продолжение потока
  после перезапуска; остановка хода.
- Запросы Codex на выполнение команд и изменение файлов показываются в ленте с командой, папкой
  и причиной: «Разрешить один раз», «Разрешить на сессию», «Отклонить».
- Модели, плагины, MCP-серверы и навыки загружаются у Codex для каждого аккаунта.
- Исчерпание лимита останавливает работу и предлагает «Управлять использованием», «Повторить»
  или выбрать другой аккаунт вручную; автоматического переключения нет.
- Процессы Codex получают только разрешённые переменные окружения и живут в собственном Job
  Object: при закрытии приложения завершается всё дерево, включая вспомогательный `git`.

### Изменения

- Новый дизайн по референсу: тёмная синяя палитра, общая верхняя строка поиска,
  навигация слева, приветственный блок и отдельные карточки проекта, сессии, Git и прав.
- Лента событий в виде вертикальных этапов: запуск сессии, каждый запрос со статусом,
  временем и длительностью, вложенные строки действий инструментов и ответ агента.
  Этапы сворачиваются по одному или все сразу; поиск и фильтры сохранены.
- Вкладки открытых проектов в строке окна. Закрытие вкладки не удаляет проект.
- Левое меню со списком проектов, сессиями активного проекта и режимом «Свернуть меню».
- Карточка «Изменения» считает изменённые, новые и удалённые файлы по данным Git.
  Карточка сессии показывает начало и длительность; использование отображается только
  если провайдер его сообщает.
- Приветственный блок можно скрыть; в сессии он показывается только на высоких окнах.
  Вкладки, свёрнутое меню и скрытое приветствие запоминаются (только настройки вида).
- Собственная строка окна с нативным перетаскиванием, сворачиванием, разворачиванием
  и закрытием с защитой несохранённых изменений.
- Карточки показывают реальные данные; статистика файлов относится только к корню папки.
  Пути показываются без служебного префикса Windows `\\?\`.
- Неиспользуемые стили удалены, дублирующиеся правила объединены.
- Цвета интерфейса сведены к единому набору токенов; тест запрещает цвета вне токенов,
  чтобы позже добавить светлую тему без правки компонентов.
- Единый термин «сессия» во всём интерфейсе.

- Интерфейс BebekonCode переведён на русский: проекты, сессии, настройки, файловый менеджер,
  подтверждения действий, поиск команд, статусы и проверка обновлений.
- Ошибки Rust-ядра, сведения о провайдерах и новые ответы локального симулятора на русском.
- Русский язык установлен для установщиков EXE и MSI, включая дополнительные сообщения WiX.
- Даты отображаются в формате ru-RU; счётчики используют русское склонение.
- Служебные подписи старых сессий и демо отображаются по-русски без изменения базы данных.
- Добавлены русская инструкция и план дальнейшей разработки.

### Исправления

- Запуск с явным `--data-dir` использует отдельный профиль и пространство защиты от второго
  экземпляра. Нативные проверки новой сборки могут работать рядом с открытым приложением,
  не изменяя основной профиль и не закрывая пользовательское окно.
- Поиск по ленте учитывает только видимые в текущем фильтре поля и ищет по показанному
  тексту, а не по исходным служебным строкам демо.
- Восстановлены версии сторонних пакетов в `Cargo.lock` и `package-lock.json`,
  повреждённые при смене версии приложения.
- Пункты навигации выровнены по левому краю; карточки правой панели прокручиваются,
  а не сжимаются.
- Окна диалогов получают уникальные подписи: при двух открытых окнах второе больше не
  озвучивается названием первого.

### Текущие ограничения

- Вход Sign in with ChatGPT и работа Codex с настоящим аккаунтом проверены автоматическими тестами
  без реального входа; полный вход и ответ модели нужно проверить на вашем аккаунте.
- Проценты 5-часового и недельного лимита OpenAI показываются, только если их сообщает Codex;
  для этого способа входа OpenAI документирует страницу использования в настройках ChatGPT.
- Генерация изображений через план ChatGPT недоступна по правилам OpenAI.
- Токен доступа живёт час; если ход длится дольше, его нужно повторить после обновления.
- Anthropic / Claude Code пока не подключён. Встроенный терминал и Git worktree — следующие этапы.
- Редактор поддерживает UTF-8 до 2 МиБ; удаляются файлы и пустые папки после подтверждения.
- Автоматическая установка обновлений и подпись выпусков пока не настроены.
- Код, пути, имена файлов, названия провайдеров и пользовательские сообщения сохраняются
  в исходном виде. Описания старых опубликованных выпусков не переписываются.

## 0.2.0 — 2026-10-06

### Added

- Real user-operated project file browser and UTF-8 text editor in the Windows desktop app.
- Create files/folders, save with Ctrl S, rename/move entries and confirmed permanent deletion
  of files/empty folders. Changes are written to the local disk through Rust IPC commands.
- Save conflict checks, same-directory staged replacement, unsaved-change decisions and bounds
  for text/file listings. Block traversal, Windows device names, junctions and `.git` internals.
- Open the selected project in Explorer or a visible external PowerShell terminal.
- Optional absolute `--data-dir` launch argument for separate local profiles and native QA.

### Changed

- Product name is now BebekonCode. A snowman with glasses, a blue scarf and a top hat appears in
  the desktop UI, Windows executable and NSIS/MSI installer icons. Existing app data is retained.

### Known limitations

- OpenAI/Claude adapters remain unavailable; the local demo is a simulation without file tools.
- The built-in editor supports UTF-8 text up to 2 MiB. Nonempty-folder deletion, other encodings
  and binary editing use external Windows tools. File removal is permanent, not the Recycle Bin.
- PowerShell opens externally; embedded terminal, isolated worktrees and agent tool approvals
  remain future work. Manual file operations are not an OS sandbox against hostile processes.
- Releases are not code-signed. GitHub update checks work; installation is still manual.

## 0.1.0 — 2026-10-06

Initial development slice. This release is not the complete production V1.

### Added

- Rust/Tokio core separated from the React/Tauri 2 Windows desktop client.
- Local project folders, immutable account-bound sessions and SQLite/WAL migrations.
- Parallel simulated agent turns, streaming timeline, cancellation and persisted event replay.
- Graphite dark UI, context panel, provider/account/model controls and command palette.
- Official provider executable detection; provider adapters remain visibly unavailable.
- Read-only Git status and unified staged/unstaged diff with bounded process execution.
- Permission policy, canonical path containment, native credential store interface and redaction.
- Manual/opt-in startup GitHub release checks, SemVer comparison and release notes.
- Window state persistence, single-instance desktop, Windows NSIS/MSI packaging and CI workflows.

### Known limitations

- Only MockProvider runs. It never reads files, executes tools or modifies projects.
- OpenAI/Claude sign-in, inference, token refresh and multi-account login are not integrated yet.
- Worktrees, tool approvals, full terminal, capability delegation and artifacts are future milestones.
- Remote/mobile and automatic installation are unavailable. Updates are downloaded manually.
- Native signing certificates and Tauri automatic-update signing keys are not configured.
