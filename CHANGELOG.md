# Changelog

Every release links to a version tag and includes the same reviewed notes in GitHub Releases.

## 0.8.3 — 2026-10-09

### Изменения

- Исправлен выпуск Windows: после проверки подписи установщика CI загружает тот же проверенный манифест с прямой ссылкой на NSIS-файл. Автоматический манифест tauri-action использовал URL GitHub API и был отклонён заключительной проверкой. Выпуск 0.8.2 остался черновиком; его тег сохранён. Все подготовленные для 0.8.2 изменения включены ниже.

- Режим «Полный доступ» для Codex по решению владельца проекта: выбирается вручную для конкретного чата после красного предупреждения, никогда не включается по умолчанию. Codex работает без песочницы и без подтверждений (`dangerFullAccess`, `approvalPolicy=never`); настройка песочницы Windows в этом режиме не требуется. Раунды проверки и подзадачи авторазбиения всегда остаются только на чтение. Для Claude режим недоступен и отклоняется ядром. Обновлены AGENTS.md и документ соответствия.
- Проект локального computer use (`docs/computer-use.md`): собственный MCP-сервер со скриншотами, мышью и клавиатурой, подтверждением каждого действия в любом режиме доступа и индикатором управления. Пока не реализован.
- Полная история чата: интерфейс больше не обрезает её до последних 600 событий и не заменяет текущую страницу старой. При открытии сначала показываются последние сообщения, затем догружается вся сохранённая история; позиция чтения при этом не сдвигается.
- Навигация по вопросам справа: метки каждого вопроса, при наведении — список вопросов; переход раскрывает свёрнутый этап и сбрасывает скрывающий его фильтр.
- Удаление чата из боковой панели (значок при наведении или правая кнопка мыши) с подтверждением. Удаляются чат, его участники, подзадачи и локальная история в одной транзакции; выполняющийся чат удалить нельзя. Файлы проекта и история на стороне провайдера не затрагиваются.
- Собственное контекстное меню вместо браузерного: копирование выделенного текста, выделение сообщения, удаление чата. В полях ввода остаётся системное меню.
- Под последним завершённым ответом в проекте с Git показана сводка изменений: число файлов и строки `+N −M`, первые файлы со счётчиками. Нажатие открывает окно просмотра: список файлов слева, подсвеченный diff выбранного файла справа. Сводка учитывает все незафиксированные изменения рабочего дерева, а не только последний запуск; строки новых неотслеживаемых файлов не подсчитываются, пересечение индекса и рабочего дерева помечается «≈».
- Команда по умолчанию при подключённых ChatGPT и Claude: Codex — координатор (команды, проверки, итог), Claude — исполнитель (анализ кода, правки, интерфейс). Распределение основано на доступных инструментах, а не на замерах качества моделей. Доступ остаётся по умолчанию и выбирается пользователем.
- В команде с одним участником пропущен раунд, в котором участник перечитывал собственный результат: проверку выполняет координатор при сборке ответа. Координатор завершает ответ кратким резюме изменений и проверок.
- Лимиты подписок остаются на экране, даже если последнее обновление не удалось: под процентами показано предупреждение и время, на которое актуальны данные. Новое успешное получение квоты снимает только ошибку обновления; прочие сообщения аккаунта сохраняются. Пустое уведомление больше не обновляет время проверки старых процентов.
- Боковая панель в маленьком окне: список проектов и чатов всегда занимает не меньше 132 px, а блок лимитов и нижние кнопки прокручиваются. В свёрнутом меню всплывающая панель лимитов не обрезается.
- Меню доступа и выбора модели подстраиваются под место над кнопкой и не выходят за верхнюю границу окна.
- Окна: Escape обрабатывает только верхнее окно; поле с автофокусом (поиск Ctrl+K) сохраняет фокус; во время установки обновления настройки не закрываются ни крестиком, ни Escape, ни кликом по фону.
- Кнопки файлового менеджера используют общее оформление; меню настроек вмещает крупный текст; в палитре команд подсвечена команда, которую запустит Enter.
- Единая шкала скруглений, плавное появление окон и меню (отключается системной настройкой уменьшения анимации), подсветка текущего пункта навигации. Цвета ползунка и теней переведены в токены тем; проверка токенов охватывает оба файла стилей.

### Текущие ограничения

Проценты лимитов показываются только при наличии в официальном ответе CLI. Для Claude `/usage` может не вернуть квоты подписки; в этом случае отображается статус CLI. Получение лимитов и запуск полного доступа на реальных аккаунтах пользователя в этой сборке не проверены. Запрет доступа к учётным данным сохраняется как правило задачи; полный доступ не обеспечивает изоляцию таких файлов средствами песочницы. Computer use пока не реализован. Ограничения 0.8.1 сохраняются для режимов с песочницей.

### Проверки

Исходники 0.8.2 прошли полный GitHub CI, включая браузерные тесты Chromium; собранный Windows-установщик прошёл проверку подписи обновления и отказа для изменённого файла, а упакованный hook Claude — отдельный аудит. Для 0.8.3 повторены локальные проверки версий, Prettier, Rust fmt/check/test/Clippy, TypeScript, 28 тестов Vitest и сборка интерфейса. Повторная сборка и проверка артефактов 0.8.3 выполняются в релизном CI перед публикацией.

## 0.8.1 — 2026-10-09

### Изменения

- Проверка готовности песочницы Codex перед запуском задач. При отсутствии настройки показана понятная инструкция вместо попыток продолжать работу через отдельные разрешения на команды.
- Состояние и кнопка штатной настройки песочницы Windows в аккаунте ChatGPT. Настройку выполняет официальный Codex; системное подтверждение остаётся в Windows. Активные задачи этого аккаунта защищены от перенастройки.
- Запросы разрешений учитывают доступные решения CLI, а сетевые запросы показывают адрес и протокол. «Разрешить в этом контексте» больше не обещает разрешение всех действий команды.
- Уточнены режимы доступа в настройках и карточках агентов. Codex использует штатный авторежим внутри песочницы; Claude сохраняет собственные режимы подтверждения правок.
- В режиме «Только чтение» запросы Codex на дополнительный доступ отклоняются с объяснением: взаимная проверка команды не получает права записи через карточку разрешения.
- Исправлено отклонение допустимых абсолютных путей Claude при другом написании корневой папки Windows. Проверки выхода из проекта, ссылок и учётных данных сохранены. Тест параллельной работы больше не зависит от короткой задержки планировщика.
- Горячие клавиши сохранения, поиска и создания чата работают и с русской раскладкой клавиатуры.

### Текущие ограничения

Настройку Windows нужно запустить кнопкой «Аккаунты → ChatGPT → Песочница Windows» и при необходимости подтвердить системный запрос. Отказ или ограничения Windows не обходятся. Автоматическое выполнение за пределами разрешённых границ не предоставляется. Отдельное подтверждение каждой правки Codex пока недоступно; режим «По правилам провайдера» сообщает об этом явно.

Настройка с реальным подтверждением UAC и команды моделей на живой подписке не проверены автоматически. Проверены RPC-сценарии настройки, отказа и занятости, ограниченные варианты разрешений и штатная проверка готовности установленного Codex CLI без запросов к модели. Ограничения Claude, вложений и каталога плагинов из 0.8.0 сохраняются.

## 0.8.0 — 2026-10-08

### Изменения

- Крупный ползунок обдумывания со сбросом, названием модели и выбранным уровнем; меню доступа с описанием режимов. Настройки участников команды доступны независимо. Правки участников выполняются последовательно, проверка результатов остаётся на чтение.
- Вложения через скрепку, вставку и перетаскивание: изображения передаются как визуальный ввод, DOCX/XLSX/PPTX — как локально извлечённый текст. Другие форматы передаются локальным файлом с явным описанием ограничений. До 8 файлов, 20 МиБ каждый / 40 МиБ всего; изображения до 4 МиБ каждое / 6 МиБ всего. Rust проверяет содержимое изображений, имена, размер и пути; при ошибке подготовки удаляет только созданные этой операцией файлы.
- Текстовый просмотр PPTX с комментариями к абзацам слайдов. Исходный документ не изменяется.
- Открытый каталог OpenAI и Claude: поиск, фильтр провайдера, обновление и переход к источнику. Просмотр доступен без аккаунта; установка и исполнение плагинов из каталога пока недоступны.
- Точные версии Claude Opus/Sonnet/Haiku, фактический ID модели из ответа CLI и поддерживаемые каждой моделью уровни обдумывания. Запрошенный уровень явно отличается от настройки по умолчанию; провайдер может его ограничить.
- Лимиты ChatGPT запрашиваются через официальный `account/rateLimits/read`. Для Claude подключена встроенная команда `/usage` без генерации ответа, инструментов, MCP, плагинов и проектных настроек. Проценты отображаются только при наличии в официальном ответе; иначе показаны статус CLI и отсутствие данных.
- Публичный ход работы и сообщения участников команды видны в общем чате, этапы проверки отделены от выполнения. Скрытые рассуждения Claude не запрашиваются и не сохраняются.

### Текущие ограничения

Ранняя версия. Живые подписки и проценты Claude после входа пользователя в этой сборке не проверены. `/usage` может вернуть только стоимость/токены сессии, без квот подписки. Не используются cookies, данные входа других приложений или неофициальные endpoints.

Каталог пока не устанавливает плагины: production-вызовы OpenAI `plugin/list`/install ещё не разрешены документацией; Claude shell/MCP/плагины/навыки в защищённом режиме Windows недоступны. Источники каталогов могут содержать сторонние плагины; присутствие в каталоге не означает проверку или доступность аккаунту.

Передача видео, аудио, PDF и произвольного файла не означает встроенного анализа кадров, распознавания речи/OCR или наличия конвертера у агента. Office-просмотр и извлечение текста упрощены: без точной вёрстки, графиков, макросов и пересчёта формул. Комментарии хранятся отдельно в SQLite. Полный доступ с отключением защит не предлагается. Authenticode отсутствует; пользовательская установка обновления с перезапуском требует отдельной проверки.

### Проверки

Пройдены cargo fmt/check/test/clippy, npm typecheck/test/build и проверка форматирования: 59 тестов Rust, 23 Vitest и 21 сценарий интерфейса (исправленный сценарий разрешений повторно проверен отдельно). Проверены PPTX, разделение этапов команды, последовательная работа участников с записью, защита путей и очистка неудачной подготовки вложений.

В собранном EXE проверены реальная загрузка фото/TXT, копии на диске, сохранение истории после перезагрузки, CSV-комментарии в SQLite, Git, отмена и передача контекста с демо-провайдером, обнаружение официального Claude CLI и список моделей без входа. Оба живых публичных каталога вернули суммарно 380 предложений. Проверены мост подтверждений, подпись установщика и отказ при изменённом пакете/неверной версии. Живые ответы подписок эти проверки не заменяют.

## 0.7.0 — 2026-10-08

### Команда рядом с перепиской

- Все участники команды теперь видны карточками над нижними параметрами чата: модель, роль, обдумывание и доступ. Нажатие открывает настройки конкретного участника; раскрывать правую панель больше не нужно.
- Каждый рабочий контекст, раунд обсуждения и общий итог получают явный инструктаж о составе команды, своей роли, общей задаче и реальном механизме сотрудничества. Коллеги передают вопросы через результаты; приложение проводит один раунд проверки и собирает единый ответ. Свободного инструмента вызова других агентов пока нет.

### Более простой интерфейс и просмотр файлов

- Настройки показывают один выбранный провайдер, технические сведения свернуты; у Claude убраны повторяющиеся пустые списки расширений. В создании команды раскрывается один участник за раз, при этом настройки остальных сохраняются.

- Страница плагинов получила поиск, фильтры по типу, карточки со статусом и назначение инструментов конкретному агенту. Установка новых расширений по-прежнему выполняется официальным CLI.
- Добавлен локальный просмотр DOCX/XLSX/CSV/TSV/Markdown/TXT с комментариями к абзацам и ячейкам, фильтрами, отметкой «Решено» и переносом замечаний в черновик чата. Новая миграция 0003 хранит замечания отдельно от исходных документов. Старые миграции не изменены.

- Процессы Codex получают только разрешённые переменные окружения и живут в собственном Job
  Object: при закрытии приложения завершается всё дерево, включая вспомогательный `git`.

### Изменения

- Новый дизайн по референсу: тёмная синяя палитра, общая верхняя строка поиска,
  навигация слева, приветственный блок и отдельные карточки проекта, сессии, Git и прав.
- Лента событий в виде вертикальных этапов: запуск сессии, каждый запрос со статусом,
  временем и длительностью, вложенные строки действий инструментов и ответ агента.
  Этапы сворачиваются по одному или все сразу; поиск и фильтры сохранены.
- Вкладки открытых проектов в строке окна. Закрытие вкладки не удаляет проект.
- Левое меню со списком проектов, сессиями активного проекта и режимом «Свернуть меню».
- Карточка «Изменения» считает изменённые, новые и удалённые файлы по данным Git.
  Карточка сессии показывает начало и длительность; использование отображается только
  если провайдер его сообщает.
- Приветственный блок можно скрыть; в сессии он показывается только на высоких окнах.
  Вкладки, свёрнутое меню и скрытое приветствие запоминаются (только настройки вида).
- Собственная строка окна с нативным перетаскиванием, сворачиванием, разворачиванием
  и закрытием с защитой несохранённых изменений.
- Карточки показывают реальные данные; статистика файлов относится только к корню папки.
  Пути показываются без служебного префикса Windows `\\?\`.
- Неиспользуемые стили удалены, дублирующиеся правила объединены.
- Цвета интерфейса сведены к единому набору токенов; тест запрещает цвета вне токенов,
  чтобы позже добавить светлую тему без правки компонентов.
- Единый термин «сессия» во всём интерфейсе.

- Интерфейс BebekonCode переведён на русский: проекты, сессии, настройки, файловый менеджер,
  подтверждения действий, поиск команд, статусы и проверка обновлений.
- Ошибки Rust-ядра, сведения о провайдерах и новые ответы локального симулятора на русском.
- Русский язык установлен для установщиков EXE и MSI, включая дополнительные сообщения WiX.
- Даты отображаются в формате ru-RU; счётчики используют русское склонение.
- Служебные подписи старых сессий и демо отображаются по-русски без изменения базы данных.
- Добавлены русская инструкция и план дальнейшей разработки.

### Исправления

- Запуск с явным `--data-dir` использует отдельный профиль и пространство защиты от второго
  экземпляра. Нативные проверки новой сборки могут работать рядом с открытым приложением,
  не изменяя основной профиль и не закрывая пользовательское окно.
- Поиск по ленте учитывает только видимые в текущем фильтре поля и ищет по показанному
  тексту, а не по исходным служебным строкам демо.
- Восстановлены версии сторонних пакетов в `Cargo.lock` и `package-lock.json`,
  повреждённые при смене версии приложения.
- Пункты навигации выровнены по левому краю; карточки правой панели прокручиваются,
  а не сжимаются.
- Окна диалогов получают уникальные подписи: при двух открытых окнах второе больше не
  озвучивается названием первого.

### Текущие ограничения

- Вход Sign in with ChatGPT и работа Codex с настоящим аккаунтом проверены автоматическими тестами
  без реального входа; полный вход и ответ модели нужно проверить на вашем аккаунте.
- Проценты 5-часового и недельного лимита OpenAI показываются, только если их сообщает Codex;
  для этого способа входа OpenAI документирует страницу использования в настройках ChatGPT.
- Генерация изображений через план ChatGPT недоступна по правилам OpenAI.
- Токен доступа живёт час; если ход длится дольше, его нужно повторить после обновления.
- Anthropic / Claude Code пока не подключён. Встроенный терминал и Git worktree — следующие этапы.
- Редактор поддерживает UTF-8 до 2 МиБ; удаляются файлы и пустые папки после подтверждения.
- Автоматическая установка обновлений и подпись выпусков пока не настроены.
- Код, пути, имена файлов, названия провайдеров и пользовательские сообщения сохраняются
  в исходном виде. Описания старых опубликованных выпусков не переписываются.
