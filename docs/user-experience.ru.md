# Рабочая область BebekonCode

## Навигация

Проекты раскрываются в папки с чатами; значок обозначает обычный разговор, команду или авторазбиение. Вне проектов эти три режима имеют отдельные списки. Один чат показывается в одном месте. Выбор папки открывает её последний чат; стрелка сворачивает папку, не переключая текущий разговор. Плюс возле проекта создаёт привязанный чат, плюс возле режима — разговор без проекта с выбранным режимом.

«Новый чат» открывает выбор режима и исполнителей. Режим задаётся при создании; существующий разговор не превращается незаметно в другой тип. Модель, доступ и инструменты можно менять для следующего сообщения. Смена аккаунта или провайдера требует явной передачи контекста.

## Переписка

Чат занимает основную часть окна. Пользователь пишет справа; ответы агента или команды находятся слева. История действий свёрнута, поиск доступен по кнопке «История». При свёрнутом ответе запрос пользователя, ошибки и карточки разрешений остаются видимыми.

У команды один итоговый ответ. Участники возвращают результаты своих частей задачи; основной агент проверяет их и собирает итог. На экране показывается фактический этап работы, полученный из событий ядра, без имитации разговора моделей или раскрытия скрытых рассуждений.

Меню «Команда» показывает состав и настройки участников. Раскрывается поверх содержимого и закрывается стрелкой, Escape или нажатием вне меню. Результат подзадачи можно открыть в отдельном контексте и вернуться в основной чат. Подзадачи прошлых запросов сохраняются в списке.

## Инструменты

Файлы и Git-изменения открываются отдельными окнами. Терминал запускает PowerShell в папке проекта; встроенного терминала пока нет. В «Плагины» показан каталог официально подключённых инструментов выбранного аккаунта. Кнопка назначения открывает персональные настройки агента; новые расширения устанавливаются через официальный CLI.

## Границы

Параллельные участники анализируют проект только на чтение; изменения делает основной агент с разрешениями чата. Ошибка или остановка команды не подменяется успешным итогом. Повышение доступа требует решения пользователя. Неподдерживаемые провайдеры и инструменты обозначены как недоступные. Тема и размер текста сохраняются локально и не затрагивают данные аккаунтов.
