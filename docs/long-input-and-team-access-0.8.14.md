# Длинные сообщения и права участников — 0.8.14

Исправлены две собственные блокировки приложения:

1. HTML textarea ограничивала ввод 16 000 UTF-16 символами; ядро независимо проверяло предел
   32 000 UTF-8 байт. Поэтому русскоязычное сообщение могло дополнительно не пройти отправку.
   Оба ограничения удалены из отправки, живого уточнения, очереди и редактирования очереди.
   Удалено также обрезание переносимых в чат замечаний из просмотра файлов. Текст не сокращается,
   не разбивается на скрытые модельные запросы и не заменяется автоматически сводкой. Реальное
   окно модели и технические ограничения интеграции не становятся бесконечными.
2. Версия 0.8.11 принудительно делала всех второстепенных участников read_only и очищала инструменты
   в исполняемых подзадачах. Теперь в обычной и автоматической команде применяются явно выбранные
   пользователем права, поддерживаемые инструменты, модель и обдумывание. Первоначальный выбор
   интерфейса по-прежнему read_only. Сохранённые пользовательские чаты автоматически не повышают права.

В настройках участника выберите «По правилам провайдера» или «Авто в проекте», затем нужные плагины,
MCP и навыки. «Только чтение» и Plan не разрешают исполняемые внешние инструменты. Каталог принадлежит
аккаунту этого участника; подключение к другому аккаунту не копируется автоматически. Claude-плагины,
не поддержанные текущим адаптером, не объявляются рабочими; поддерживаемые Claude MCP и инструкции
навыков доступны. Полный доступ обычного участника требует существующего предупреждения. Для
автоматических участников полный доступ и Fast недоступны.

Подзадачи с записью выполняются последовательно, без одновременных правок общего проекта.
Ведущий получает короткие отчёты и проверяет уже выполненные изменения вместо повторной реализации.
При смене доступа/инструментов меняется ключ сохраняемой сессии участника; старый контекст с другими
правами не используется. История остаётся сохранённой. Настройки изменяются в карточке участника,
а не в завершённом результате отдельной подзадачи. Опубликованные миграции не изменялись.

Официальные источники проверены: [Codex app-server](https://learn.chatgpt.com/docs/app-server),
[Claude permissions](https://code.claude.com/docs/en/permissions),
[Claude CLI](https://code.claude.com/docs/en/cli-reference).
