# BebekonCode 0.8.11 — локальное обновление, 14 октября 2026

Продолжение [аудита](claude-desktop-audit-2026-10-14.md). Старый отчёт описывает состояние
до этой доработки; его перечень отсутствовавших функций частично заменён результатами ниже.
Пользователь разрешил установку и Claude Bypass с предупреждением и обязательным согласием
на управление компьютером. Проверки выполнены без модельных запросов Claude и Codex.

## Реализовано

| Пункт                     | Реализация                                                                                                                  |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Постоянные разрешения     | Точные Edit/Write правила аккаунта и проекта, явное добавление/отзыв в «Задачи и версии», штатный permissions.allow         |
| Режимы Claude             | Manual, Accept edits, Plan, Auto, Bypass; предупреждение перед Bypass; фактический режим из CLI                             |
| Ветка                     | Официальный SDK forkSession для Claude и thread/fork для Codex без inference; ограниченный публичный контекст для остальных |
| Изоляция                  | Отдельный Git worktree по выбору при ветвлении; общие папки защищены от одновременных писателей приложения                  |
| Очередь                   | Сохраняется в SQLite; последовательная отправка, отмена, явное продолжение после перезапуска/ошибки/смены настроек          |
| История файлов            | Автоматические точки перед сообщениями с правом записи и ручные точки; до/после; выборочное восстановление и удаление точек |
| Защита при восстановлении | Проверка fingerprint текущего файла, резервная точка перед заменой, отсутствие git reset/автослияния                        |
| Уведомления               | Видимое уведомление в приложении о завершении/ошибке и переход к чату                                                       |
| Отображение               | Три режима событий, диагностические отчёты и существующие Markdown/вложения/таблицы/диаграммы/diff                          |

## Границы возможностей

- Режим разрешений Claude Auto (отдельно от «Автокоманды») может быть недоступен выбранной модели/аккаунту и может расходовать дополнительные
  вызовы классификатора при реальном использовании. В тестах классификатор не запускался.
- Bypass предназначен для доверенной изолированной среды. Произвольный shell-код невозможно
  считать безопасным только по анализу текста команды; это не песочница ОС.
- Постоянные правила в этой реализации ограничены точными Edit/Write путями. Бессрочное
  разрешение произвольных MCP/компьютерных действий не предлагается.
- Контрольные точки — локальные снимки приложения, не перемотка подписанного диалога Claude.
  Пределы: 256 КиБ на текстовый файл, 16 МиБ на точку, 100 точек на чат. Новые файлы не удаляются.
  Для двоичных, игнорируемых и защищённых файлов применяйте обычные инструменты резервирования.
- Worktree требует Git и HEAD; зависимости/ignored/защищённые файлы пропускаются, общий объём
  копируемых файлов ограничен 512 МиБ. Рабочие копии не сливаются и не удаляются автоматически.
- Все восемь сравнительных проектов подготовлены; реальное сравнение подписочных расходов
  исключено пользователем. Равенство лимитов с Claude Desktop и полная идентичность продукта
  не заявляются.

## Проверки

- `cargo fmt --all -- --check`, `cargo check --workspace -j1`, `cargo clippy --workspace -j1 -- -D warnings`: успешно.
- `cargo test --workspace -j1`: 124 пройдено; 5 проверок реальной среды провайдера явно пропущены. Авторизованных модельных запусков нет.
- `npm run typecheck`, `npm test` (45 тестов), `npm run build`: успешно. Включён тест истории из 1200 ходов / 18000 событий.
- 30 браузерных сценариев прошли в совокупности основного запуска и адресных повторов. Устаревшие ожидания названия роли/Автокоманды и доступности плагинов специалиста исправлены; финальный адресный повтор прошёл.
- CLI/RPC fixtures проверяют Claude и Codex: resume, привязку аккаунта, разрешения, Fast, отмену, usage/диагностику, fork. Публичная схема Codex 0.160.1 проверена локальным генератором без inference.
- `node scripts/claude-session-audit.mjs`: официальный SDK копирует искусственную сессию с новыми идентификаторами, не меняя исходник и не вызывая модель.
- Восемь пар одинаковых сравнительных проектов подготовлены с совпадающими SHA-256. Реальные токены до/после и сравнение с оригинальным Claude Code не измерялись по ограничению пользователя.
- `node scripts/native-smoke.mjs` и `node scripts/native-workflows.mjs`: успешно на release-файле и повторно на **установленном** 0.8.11 через `BEBEKON_TEST_BINARY`, в отдельных временных профилях. Проверены настоящий Tauri IPC, SQLite, файлы/конфликты/Unicode, вложения, Git diff, очередь, worktree, контрольные точки, история и команда.
- Нативная команда из двух агентов: подробная задача — 2 запуска, «Продолжай» — 1; отдельного planning-запуска нет. Очередь завершила оба задания; выборочное восстановление вернуло исходный текст; worktree изолирован.
- `node scripts/check-versions.mjs`: версия 0.8.11 согласована. Опубликованные миграции 0001–0004 совпадают с v0.8.10; добавлены 0005 и 0006. Теги не менялись.

Командная архитектура и численные изменения количества запусков: [отчёт](multi-agent-efficiency-0.8.11.md).
Сокращение запусков не является измерением процента экономии токенов.
