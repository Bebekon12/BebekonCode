# Что ещё осталось сделать в BebekonCode

Состояние на 8 октября 2026 года, версия 0.7.0. Эталон пользовательского сценария — Codex:
создать чат, выбрать подписку и исполнителя, описать задачу, менять настройки прямо в чате.

## Уже реализовано

- Windows EXE и установщики EXE/MSI, русский интерфейс, логотип, локальные файлы, Git и история SQLite.
- Официальный адаптер OpenAI / Codex через Sign in with ChatGPT, отдельные профили аккаунтов, запросы разрешений и остановка дерева процессов.
- Официальный неизменённый Claude Code CLI: отдельный вход, файлы проекта с подтверждениями, обычные и командные чаты, авторазбиение, передача контекста. На Windows оболочка и расширения Claude недоступны.
- Новый чат без обязательной папки. Обычный чат, команда с ролями и автоматическое разбиение.
- Модель, уровень рассуждения и доступ возле ввода. Персональный выбор установленных расширений для каждого участника.
- Явная передача контекста другому исполнителю с сохранением чата. При неудаче исполнитель сохраняется.
- Ограниченный параллельный анализ: до двух задач одновременно, до четырёх задач на запрос. Собственные потоки и история, общий контекст, один раунд обсуждения в команде и итог основного агента.
- Сжатие контекста средствами Codex, подписанные обновления из GitHub внутри приложения.
- Все модели команды возле ввода, ползунок обдумывания, компактные настройки, поиск расширений и реальные снимки лимитов подписок слева.
- Просмотр DOCX/XLSX/CSV/TSV/Markdown/TXT с локальными комментариями, отметками решения и черновиком обсуждения; привязка к версии файла и защита несохранённых замечаний.

Локальное демо остаётся симулятором. Проверки ядра с тестовыми провайдерами подтверждают
протокол оркестрации, сохранение истории, настройки, передачу и отмену. Они не подтверждают
качество решений настоящих моделей и работу на живых подписках.

## Следующие обязательные этапы

1. **Живая команда Claude + GPT.** После входа в собственные аккаунты проверить реальные ответы, изменения после подтверждения, авторазбиение и переход в обе стороны. Протокольные тесты и вход в пустой профиль не заменяют эту проверку. Для shell и расширений Claude сначала нужен официальный способ обеспечить системную песочницу на Windows.
2. **Живые сценарии.** Проверить ChatGPT-подписку, фактическую доступность моделей, перенос между аккаунтами, реальные плагины/MCP/навыки, автосжатие длинного диалога, ошибки и квоты. Проверить установку обновления и перезапуск на отдельной установленной копии.
3. **Изолированные изменения.** Git worktree для каждого параллельного исполнителя, просмотр diff и осознанное применение результатов. Сейчас параллельные исполнители анализируют проект в режиме только чтения; изменения выполняет основной агент.
4. **Полный интерфейс расширений.** Установка/удаление плагинов, добавление MCP и их авторизация внутри программы. Сейчас доступны выбор и назначение уже установленных инструментов; установка — в официальном CLI.
5. **Долгие команды.** Граф зависимостей, дополнительные обсуждения и делегирование по запросу участника, бюджет/лимиты команды, продолжение завершённых этапов после сбоя, архивирование и экспорт чатов. Сейчас число участников и раундов намеренно ограничено, автоматического возобновления после сбоя нет.
6. **Редактор и терминал.** Встроенный интерактивный терминал, подсветка кода, вкладки, поиск по проекту, наблюдение за внешними изменениями, другие кодировки, Корзина и расширенные операции с папками.
7. **Документы.** Точная вёрстка Office, изображения/графики, форматы PDF/DOC/XLS, экспорт замечаний в исходный документ, перенос привязок при переименовании и больших изменениях. Сейчас комментарии хранятся отдельно, просмотр упрощённый.
8. **Распространение.** Authenticode, резервное копирование/восстановление, длительные проверки на чистой Windows, масштабирование, доступность и аудит безопасности.

Генерация изображений через текущий путь ChatGPT-подписки не поддерживается OpenAI.
Отдельный официальный API для графики потребует отдельного подключения; выбор роли
«дизайнер» сам по себе не добавляет инструмент генерации изображений.
