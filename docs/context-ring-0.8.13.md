# Контекст: компактный индикатор и очистка сборок — 0.8.13

По запросу владельца плашка «Контекст —» заменена небольшим кольцом. В обычном чате кольцо
составляет одну строку с моделью; в компактной и широкой команде находится у модели ведущего.
Ни отдельного ряда над параметрами, ни постоянно видимой подписи больше нет. Значение доступно
при наведении, подробности — по нажатию. Неизвестное заполнение остаётся неизвестным.

Панель открывается поверх интерфейса в пределах окна, не обрезается боковой колонкой и закрывается
по Escape или нажатию снаружи. Настройки провайдера остаются значениями по умолчанию; сохранённый
явный выбор пользователя не сбрасывается. Логика провайдеров и формат пользовательских данных
в этой доработке не менялись; миграций базы не добавлено.

Проверки: Rust fmt/check/clippy, 133 Rust-теста, TypeScript, 50 frontend-тестов, production build,
7 браузерных сценариев (контекст, очередь, команда, компактный/широкий экран). Первый повтор
Rust-тестов прервался из-за нехватки памяти Windows; повтор без incremental и с одним потоком
тестов прошёл. Запросы к моделям для проверки не выполнялись.

Размеры до очистки: target занимал около 41,46 ГиБ, основная папка зависимостей около 0,44 ГиБ.
К удалению допускаются только проверенные генерируемые каталоги. Временные профили удаляются
лишь при наличии базы с исключительно mock-аккаунтами/сессиями; активные процессы и reparse points
проверяются отдельно. Исходники, Git, установленные пользовательские профили и резервные копии
не входят в список удаления.

Результаты установки и фактической очистки будут добавлены после завершения.
