# BebekonCode — локальная среда разработки с ИИ

Приложение для Windows на Rust, Tauri 2, React и SQLite.
[Репозиторий](https://github.com/Bebekon12/BebekonCode) ·
[Выпуски](https://github.com/Bebekon12/BebekonCode/releases) ·
[Что ещё осталось сделать](docs/roadmap.ru.md)

**0.8.1 — ранняя версия с Claude и Codex.** Работают локальные файлы, проекты, история, Git, подписанные обновления и официальные адаптеры OpenAI / Codex и Anthropic / Claude Code. Подключённые аккаунты можно объединить в команду. Протокол и оркестрация проверяются локально; взаимодействие на живых подписках ещё требует проверки после собственного входа пользователя.
Локальное демо показывает потоковый вывод и остановку; оно не читает и не меняет файлы.
Интерфейс, сообщения приложения и установщики на русском языке.
Оформление использует локальный Inter, нейтральные цвета и текст переписки 17 px.
В «Настройки → Основные» доступны светлая/тёмная тема и крупный текст (19 px).
Панель проекта открывается кнопкой в правом верхнем углу; настройки вида сохраняются.
Inter распространяется с лицензией SIL OFL 1.1 в public/fonts/OFL.txt; шрифт не загружается с внешних сервисов.

## Установка и запуск

Для Windows 11 x64 скачайте `BebekonCode_0.8.1_x64-setup.exe` из
[GitHub Releases](https://github.com/Bebekon12/BebekonCode/releases).
Для запуска без установки используйте `BebekonCode_0.8.1_x64.exe`; нужен установленный WebView2.
Доступен и установщик MSI на русском. Браузер, Node.js и npm пользователю не нужны.

## Рабочая область

Проекты слева раскрываются в дерево чатов. Разговоры без проекта разделены на обычные чаты,
команды агентов и авторазбиение; плюсы возле разделов создают чат нужного типа.
Ваши сообщения находятся справа, ответы — слева. Команда выдаёт один общий итог;
все модели и доступы видны карточками возле поля ввода. Нажмите на участника, чтобы поменять модель, обдумывание, доступ и инструменты. Отдельные результаты доступны в меню «Команда».
Файлы, PowerShell и изменения Git открываются из заголовка. Раздел «Плагины» показывает
открытые каталоги OpenAI/Claude и подключённые инструменты. Установка из каталога пока недоступна; существующие доступные инструменты можно назначить конкретному агенту.
[Правила пользовательского сценария](docs/user-experience.ru.md).

## Документы, таблицы и лимиты

Скрепка возле ввода, вставка и перетаскивание прикрепляют файлы к сообщению. PNG/JPEG/GIF/WebP передаются моделям как изображения; из DOCX/XLSX/PPTX извлекается текст. Видео, аудио, PDF и прочие файлы можно передать локальным путём, но встроенного анализа кадров, OCR и расшифровки нет. До 8 файлов, 20 МиБ каждый / 40 МиБ всего; изображения до 4 МиБ каждое / 6 МиБ всего.

В **Файлах проекта** откройте DOCX, XLSX, PPTX, CSV или TSV: появится просмотр с комментариями.
Для Markdown/TXT выберите **Просмотр и комментарии**. Нажмите на абзац или ячейку,
добавьте замечание, отметьте его решённым или перенесите открытые замечания в черновик чата.
Отправка этого черновика всегда выполняется пользователем. Комментарии хранятся локально
в SQLite отдельно от исходного файла и привязаны к пути и версии файла. После внешнего
изменения нажмите **Обновить**; старые замечания помечаются как относящиеся к предыдущей версии.
Переименование файла не переносит его комментарии автоматически.

Просмотр Office упрощённый: без точной вёрстки, изображений, графиков, макросов и пересчёта
формул (показываются сохранённые значения). Поддерживаются UTF-8 CSV/TSV, обычные DOCX/XLSX
до 20 МиБ; старые DOC/XLS, зашифрованные документы и PDF пока недоступны. Большие документы
показываются частично с предупреждением.

**Лимиты подписок** слева внизу показывают все добавленные аккаунты и реальные снимки лимитов.
Обновление — кнопкой рядом с заголовком. Если провайдер не сообщает остаток, цифр нет;
ссылка **Использование** открывает официальную страницу провайдера. Для Claude в текущем
режиме запускается официальный `/usage`: если CLI не возвращает проценты, показан его текстовый статус без выдуманного остатка. Работа квот после входа в живую подписку ещё требует проверки.

## Подключение Claude и команда Claude + GPT

1. Установите [официальный нативный Claude Code для Windows](https://code.claude.com/docs/en/setup). Нужна версия **2.1.293 или новее**; обновление существующего CLI — `claude update`.
2. В BebekonCode откройте **Аккаунты → Claude → Добавить аккаунт Claude → Войти через Claude Code**. В браузере откроется штатный вход Anthropic. Каждый аккаунт использует собственную папку `CLAUDE_CONFIG_DIR`; данные входа из других приложений не импортируются.
3. Для Claude Console альтернативная команда входа с нужным профилем показана под аккаунтом. После входа нажмите **Обновить**. Доступ и оплата определяются вашим аккаунтом Anthropic; BebekonCode не продаёт доступ к подписке.
4. Подключите свой аккаунт ChatGPT. В его карточке проверьте **Песочница Windows**. Если нужна настройка, нажмите **Настроить песочницу Windows** и подтвердите системный запрос. При ошибке защита не отключается; сначала устраните указанную причину.
5. Выберите **Новый чат → Команда агентов**, назначьте основного агента и участника: например Claude и Codex. Для каждого выберите аккаунт, модель, уровень рассуждения и роль. Основной агент собирает один общий ответ и выполняет разрешённые изменения.

Claude также доступен в обычном чате, авторазбиении и через **Перейти** с пересказом контекста.
Sonnet, Opus и Haiku — официальные псевдонимы CLI. Можно выбрать и точную версию; доступность определяет Anthropic. Реальный ID виден в ответе. Уровень обдумывания — запрошенное значение, которое провайдер может ограничить. Проценты квоты Claude не выдумываются: если `/usage` их не сообщает, остаётся ссылка на использование Anthropic.

**Ограничения Claude на Windows:** встроенные инструменты чтения, поиска и изменения файлов в папке проекта. Доступ выбирается явно: только чтение, подтверждение или автоправки внутри проекта. Участники с записью выполняются последовательно; проверка результатов — только чтение. Команды оболочки, MCP, плагины и навыки пока отключены: у native Windows shell Claude нет системной песочницы. Используются официальный restricted mode и ограничения файловых инструментов; это не песочница ОС. Новые промежуточные папки создавайте через файловый менеджер приложения. Ошибки лимита останавливают запрос без переключения аккаунта.

## Чаты

Нажмите **Новый чат** и выберите режим:

- **Обычный чат** — один исполнитель; папка проекта необязательна.
- **Команда агентов** — основной агент и 1–2 участника с выбранными ролями. Участники анализируют задачу, получают результаты коллег и проводят один раунд обсуждения. Основной агент проверяет выводы и выполняет изменения.
- **Авторазбиение** — основной агент составляет проверяемый план из 1–4 независимых подзадач. Каждая получает отдельный поток и общий контекст. Одновременно работают до двух подзадач.

Выберите подключённый аккаунт и модель. Возле поля ввода доступны модель, уровень рассуждения,
доступ, инструменты и кнопка **Перейти**. Уровни рассуждения берутся из каталога провайдера;
локальное демо их не поддерживает. Настройки применяются со следующего сообщения.

**Авто в проекте** разрешает Codex выполнять команды и правки внутри штатной песочницы без
отдельных подтверждений. Дополнительный доступ может потребовать решения пользователя.
**Разрешить в этом контексте** относится к запросу конкретного агента; другие команды и
участники команды не получают общий доступ. В режиме **По правилам провайдера** Claude
спрашивает перед правками, а Codex использует тот же авторежим песочницы: подтверждение каждой
отдельной правки Codex пока недоступно. В режиме **Только чтение** дополнительные разрешения
Codex отклоняются, чтобы взаимная проверка не могла превратиться в запись.

**Перейти** запускает пересказ задачи текущим агентом. После успешного пересказа выбранный
исполнитель получает контекст в этом же чате. При ошибке или отмене прежняя привязка сохраняется.
Аккаунты не переключаются автоматически при лимитах. Сжатие длинного контекста выполняет официальный CLI провайдера
по порогу модели; приложение показывает полученное событие сжатия в действиях агента.

Для каждого участника Codex можно выбрать уже установленные плагины, MCP-серверы и навыки.
Выбор применяется к потоку агента, а конфигурация аккаунта на диске не переписывается.
В **Плагины** выберите аккаунт Codex: каталог, поиск, установка и удаление работают через
официальный CLI в его отдельном профиле. Каталог Unity Technologies подключается кнопкой **Unity**.
После установки начните новый чат. Каталог OpenAI зависит от входа через Codex и доступности
расширения для аккаунта; подключение внешнего сервиса может требовать отдельной авторизации.
Computer Use и desktop-интеграции здесь недоступны; hooks отключены. Установка плагинов Claude
в этом менеджере пока недоступна. Плагины, установленные провайдером по умолчанию, не удаляются.

Настройки открываются в отдельном рабочем пространстве. Подробности лимитов раскрываются
у аккаунта, а справка по вложениям и контексту — под значком информации возле поля ввода.

Участники используют песочницу только на чтение. Основной агент может менять проект, если
выбран соответствующий доступ. Запросы дополнительного доступа требуют решения пользователя.
Без проекта используется отдельная локальная папка `chat-files` внутри данных приложения.
В контекст передаются исходная цель, сохранённый пересказ и ограниченная последняя история;
если начало сокращено, это явно помечается. Это не общий бесконечный контекст всех моделей.

## Работа с файлами

Добавьте папку проекта и откройте **Файлы проекта**. Доступны просмотр папок, создание файлов
и папок, редактирование UTF-8 до 2 МиБ, сохранение (Ctrl S), переименование/перемещение и
безвозвратное удаление файла или пустой папки после подтверждения.

Перед сохранением приложение проверяет, не изменился ли файл на диске. Несохранённые изменения
требуют решения при переходе к другому файлу и закрытии окна. Сохранение сохраняет CRLF/LF.
Ссылки, Windows junction, переходы за пределы проекта, зарезервированные имена и `.git`
блокируются встроенным редактором. Права доступа и ограничения ОС сохраняют своё действие.
Гонки с недоверенными внешними процессами и сохранение специальных ACL требуют дальнейшей работы.

**Проводник** открывает проект в Windows. **PowerShell** открывает отдельное окно терминала
в папке проекта. Встроенный терминал появится позже. Двоичные файлы, другие кодировки,
большие файлы и удаление непустых папок пока обслуживаются внешними инструментами Windows.

## Обновления

Откройте **Настройки → О программе и обновления → Проверить обновления**.
Если доступен выпуск, нажмите **Установить и перезапустить**, затем подтвердите установку.
Приложение скачает setup.exe, проверит подпись, закроется и откроется после обновления.
Перед установкой остановите активные сессии; во время загрузки сохраняется прогресс.

Версии до 0.3.2 ещё не поддерживают установку внутри приложения: один раз скачайте
и запустите установщик актуальной версии из [GitHub Releases](https://github.com/Bebekon12/BebekonCode/releases/latest).
После этого следующие версии устанавливаются внутри BebekonCode. Подпись Tauri защищает
пакет обновления; отдельный Windows Authenticode пока не настроен.

## Разработка

Лимиты подписок отображаются по данным провайдеров: Codex App Server и экспериментальный
Claude Agent SDK. Для чтения лимитов Claude нужен Node.js 18+ в PATH. Если прежний вход ChatGPT
не предоставляет лимиты, в аккаунтах доступна кнопка «Войти через Codex для лимитов»;
выберите тот же аккаунт в браузере. Учётные данные этого режима хранит официальный CLI
в защищённом хранилище ОС. Проценты и сроки сброса не оцениваются, ошибки видны.

Нужны Windows 11 x64, WebView2 Runtime, Rust stable/MSVC, Visual Studio 2022 Build Tools
с C++, Windows SDK, Node.js 22+ и npm. Git необязателен для приложения, но нужен разработчику.
Electron, отдельный Chromium, постоянный Node-сервер и служба SQLite не используются.

```powershell
npm ci
npm run dev
```

Запускатель находит Cargo в `%USERPROFILE%\.cargo\bin`, если его нет в PATH.
`npm run dev:ui` и `http://localhost:1420/?preview=1` — только визуальный предпросмотр
для разработки, без реальной файловой системы. В обычной браузерной сборке приложение не работает.

```powershell
npm run package
```

Исполняемый файл: `target/release/bebekoncode-desktop.exe`. Установщики находятся в
`target/release/bundle/nsis` и `target/release/bundle/msi`.
Удаление приложения не удаляет проекты; локальные данные сохраняются.

## Проверки

```powershell
cargo fmt --all --check
cargo check --workspace --locked
cargo test --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:native
```

Последняя команда требует собранного EXE и Windows. Она проверяет настоящие WebView2/IPC
и операции на диске в отдельном временном профиле. Подключение отладчика включается только
для процесса этой проверки. Для UI-тестов с установленным Edge задайте
`$env:PLAYWRIGHT_CHANNEL = 'msedge'`. Эти проверки не заменяют полный тест установки
и настоящих провайдеров. Подробности — в [протоколе проверок](docs/validation.md).

## Данные и устройство приложения

По умолчанию база находится в `%LOCALAPPDATA%\com.bebekon.agent-workspace\workspace.db`.
`--data-dir D:\absolute\folder` выбирает отдельный локальный профиль с независимой защитой
от второго экземпляра. Основной идентификатор приложения сохраняется при переименовании,
поэтому старые проекты и история доступны после обновления.
Учётные данные провайдеров должны храниться в системном хранилище, а не в SQLite.
Телеметрии, удалённого сервера и автоматического переключения аккаунтов нет.
